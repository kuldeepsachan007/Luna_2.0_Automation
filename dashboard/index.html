How to add a new feature or test scenario

New scenario — add a Scenario: to the feature file (e.g. features/stress.feature). It shows up as a new box inside that card (hit Refresh).

New feature button — 1) add a marker in pytest.ini, 2) create features/<name>.feature (tagged @<marker>) + steps, 3) add an entry to dashboard/config.json and map it to a device. A new card appears automatically.
